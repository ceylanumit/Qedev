# Qedev — Technology Blog

A static technology blog built with HTML, CSS, JavaScript and Bootstrap 4. This project is separate from [Qedev Linux](https://github.com/ceylanumit/qedev-linux).

## Features

- Home page with a featured-content carousel.
- Article pages and category navigation for hardware, software, gaming, AI and mobile topics.
- About, contact and privacy pages.
- Responsive layouts with Bootstrap and Boxicons.

## Run locally

Clone or download this repository and open `index.html` in a browser. Alternatively, serve the repository with a local static-file server.

This repository contains the website front end, including Turkish sample content. Login and registration pages are interface mockups; no server-side authentication or content management backend is included.
